# Security policy

## Reporting a vulnerability

Please report potential vulnerabilities through a private GitHub security
advisory for this repository. Do not open a public issue, publish a proof of
concept, or include private scan inputs, domain names, DNS record contents, or
domain-level results in the report.

If private advisories are unavailable, contact the repository owner through
GitHub and request a private reporting channel before sending technical detail.

## Coordinated disclosure

We will acknowledge a report, assess reproducibility and impact, agree on a
disclosure timeline with the reporter, prepare a fix or mitigation where
applicable, and credit the reporter in release notes if they wish. Timelines
depend on severity, affected users, and whether third-party coordination is
needed. Please allow a reasonable period for investigation before disclosure.

This policy covers the scanner and release tooling. It does not authorise
publication or transfer of the private raw database, SWITCH zone snapshot,
domain lists, hashed-domain lists, sampled domains, or DNS record contents.
